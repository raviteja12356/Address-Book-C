# Address Book

A command-line based Address Book application developed using C programming.

## 📌 Project Description

This project is a console-based Address Book application that allows users to manage contact information efficiently. It provides options to add, search, edit, delete, and display contacts.

## 🚀 Features

- Add a new contact
- Search for a contact
- Edit existing contact details
- Delete a contact
- Display all contacts
- Store contact information using file handling
- Validate contact information

## 🛠️ Technologies Used

- C Programming
- Structures
- Functions
- Pointers
- File Handling
- Command Line Interface
- GCC Compiler
